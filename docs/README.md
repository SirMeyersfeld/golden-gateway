If you are new to coding, start in this order:

1. `docs/START_HERE.md`
2. `docs/CODEBASE_LOGIC.md`
3. `docs/UI_SYSTEM.md`
4. `docs/UI_ROADMAP.md`
5. `docs/DEV_WORKFLOW.md`

---

## What this app is

Golden Gateway is a React + TypeScript + Supabase web app for private equity style investing flows.

- **Investor side:** browse deals, run investment wizard, track portfolio, view documents.
- **Fund manager side:** create/manage deals, track investors, issue capital calls, edit CMS content.
